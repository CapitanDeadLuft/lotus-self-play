# UI AUTOSTART — скрипт автозапуска бот-матча за Treant

Скрипт кликает по UI Dota: **ИГРАТЬ → ИГРА С БОТАМИ → иконка Treant → ВЫБРАТЬ**.
Нужен, потому что `Engine.ExecuteCommand` у нас заглушка (нельзя стартовать матч
консольной командой `dota_start_ai_game`), а тестовое правило — одиночная игра против ботов.

## Файлы
- `src/start_bot_treant.ps1` — сам скрипт (PowerShell 7 / pwsh).
- `src/start_bot_treant.bat` — elevated-обёрка (Dota HIGH integrity → клики только elevated).

## Запуск
Из **главного меню** Dota (не из матча!):
```powershell
Start-Process D:\hake\lotus\src\start_bot_treant.bat -Verb RunAs -Wait
Get-Content D:\hake\lotus\src\start_bot_result.txt
```
Параметры (через .ps1 напрямую из elevated pwsh):
- `-MenuDelay 2` — пауза после ИГРАТЬ (с).
- `-LoadDelay 24` — пауза после ИГРА С БОТАМИ, ждать экран пика (с). Если загрузка
  дольше — увеличить; если клики попадают в загрузочный экран — увеличить.
- `-PickDelay 1` — пауза после клика по иконке (с).
- `-Solo` — дополнительно кликнуть радиокнопку ОДИНОЧНАЯ (по умолчанию она уже выбрана).
- `-DryRun` — только печатать шаги, не кликать.

## Выход из бот-матча / рестарт теста (22.11)
- ESC и `\` **не** открывают in-game меню; шестерёнка (29,25) возвращает в главное меню, но матч
  продолжает жить (кнопка «ВЕРНУТЬСЯ В ИГРУ»).
- **Убийство dota2.exe завершает локальный бот-матч** (проверено 2×): рестарт клиента → чистое
  главное меню без reconnect. Это самый быстрый способ начать новый тестовый матч.
- Консоль Dota: запускать `dota2.exe ... -console` (запуск через steam:// консоль не даёт);
  клавиша консоли — **`\`** (VK 220; в `cfg\user_keys_default.vcfg` `"\" "toggleconsole"`).

## Автозапуск через консоль/сторонние средства
`Engine.ExecuteCommand` у нас заглушка (AI-10), поэтому старт матча — только UI-клики. Консоль
используется для диагностики/выхода (`disconnect`), но синтетический ввод текста в неё нестабилен —
надёжнее kill+relaunch.

Все 4 шага подтверждены живым прогоном 21.11 (сборка 6988): скрипт выбрал
Treant Protector, экран планирования открылся. Координаты актуальны для 6988.

## Как снимались координаты
1. Скриншот всего экрана (`pc-control shot.ps1`, 3840×1080, Dota слева 0–1920).
2. Кроп нужной области через System.Drawing с увеличением (2–3×), чтобы точно
   увидеть кнопку/иконку. Полные координаты = кроп-координаты / масштаб + origin кропа.
3. OCR (`D:\LLM\ask-image.ps1`) для точных пикселей **ненадёжен** (галлюцинирует
   координаты) — использовать только визуальный кроп.

## Замечания
- Скрипт НЕ выходит из текущего матча. Запускать из главного меню. Если матч идёт —
  сначала покинуть его (в этом клиенте ESC/меню выхода капризны; проще дождаться
  конца матча или выйти через главное меню после игры).
- После клика ВЫБРАТЬ матч стартует за Treant; бот-цикл (`bot_loop_run.lua`) должен
  быть запущен (run.txt) и авто-подхватит героя.
- Раскладка сетки зависит от сортировки («Атрибуты») и языка клиента; при другой
  сортировке иконка Treant сместится.
